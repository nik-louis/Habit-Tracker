# Habitunity

Однофайловый трекер привычек с непрерывной весовой экономикой очков (валюта **INLI**), тирами нарушений и достижений, магазином наград и косметики профиля, многолетним учётом и зашифрованной облачной синхронизацией. Всё приложение — это один `index.html` без сборки, бэкенда и зависимостей.

> Экономика без резких порогов: каждый день имеет последствие — пропустил серию, штраф плавно растёт; продержался серию, бонус плавно растёт. Никаких «мёртвых зон», где ничего не важно.

---

## ✨ Возможности

- **Привычки двух типов** — ежедневные и событийные (норма N раз в месяц с линией темпа), с тегами по сферам жизни, весами (1–10) и индивидуальными настройками.
- **Геймификация:** 100 уровней, 20 рангов (Novice → God), опыт за каждую закрытую привычку по перебалансированной кривой (рассчитана на годы, а не месяцы).
- **Очковая экономика INLI (непрерывная, без порогов):**
  - Отметил — плюс вес привычки; пропустил прошедший день — минус 3×вес.
  - **Эскалация серий:** 3+ дня пропусков подряд — штраф плавно растёт к потолку −6×вес; 5+ дней выполнения подряд — бонус растёт к потолку +4×вес. Сбрасывается при первом же перерыве.
  - **Тиры нарушений и успеха** (опционально, по привычке): своя лестница строгости для срывов и своя лестница для качества выполнения, с лимитом бесплатных попыток в месяц.
  - **Осознанный пропуск («грех»):** конкретные даты в календаре или лимит «любой день» в месяц — пропуск дешевле, но не бесплатно.
  - **Денежный пул:** доход × ставка делится между провалившими норму привычками пропорционально весу — без потолка-обрыва.
  - **Бонус за идеальный день:** закрыл все привычки за день — небольшой непрерывный бонус на начисления этого дня.
  - **Пауза (архив):** привычку можно поставить на паузу — эти дни по-настоящему исключаются из подсчёта, а не просто прячутся из интерфейса.
- **Единый магазин наград:** свои награды любой цены в INLI, привязка к тегам, история покупок.
- **Вклад:** заморозь INLI на N дней — получи назад капитал плюс непрерывный бонус за срок (растёт с длительностью, без фиксированных ступеней).
- **Магазин эстетики профиля:** 76 предметов — фоны, рамки, значки, титулы. Часть покупается за INLI, часть открывается достижениями (в т.ч. два «сета» за самые сложные ачивки).
- **Достижения:** 16 штук, привязаны к реальной экономике (месяц/год в плюсе, серии, чистота от нарушений, уровень).
- **Многолетний учёт (2026–2050):** каждый год — чистый лист (галочки, доход, аналитика свои), а привычки, настройки, косметика и баланс INLI — общие. Корректные дни недели и високосные годы.
- **Аналитика:** дисциплина по месяцам, тренд баланса INLI, недельные паттерны, эффективность по тегам, серии, тепловая карта, корреляции «эффект следующего дня», итоги месяца.
- **Уведомления:** центр уведомлений с массовыми действиями (прочитать/архивировать/удалить всё), настраиваемые напоминания, тост с отменой после отметки/снятия отметки, периодическое напоминание о бэкапе.
- **Облачная синхронизация (Firebase) с шифрованием AES-256-GCM:** данные шифруются на устройстве, в облаке — нечитаемый шифротекст. Ключ выводится из пароля через PBKDF2.
- **Экспорт:** JSON, CSV, PDF, PNG — полностью локально.
- **Темы** (тёмная/светлая), акцентные цвета, заметки на день, архив/удаление с сохранением истории, версии и восстановление.

## 🚀 Запуск

### Локально
Просто открой `index.html` в браузере. Данные сохраняются в `localStorage`.

### Как сайт (GitHub Pages)
1. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root` → Save.
2. Через минуту приложение будет доступно по адресу `https://<твой-логин>.github.io/<репозиторий>/`.

### Через Netlify
Перетащи `index.html` на [app.netlify.com](https://app.netlify.com) — получишь ссылку за 15 секунд.

## ☁️ Облачная синхронизация (необязательно)

Нужна только если хочешь синхронизировать данные между устройствами.

1. Создай бесплатную базу [Firebase Realtime Database](https://console.firebase.google.com).
2. На вкладке **Rules** вставь и опубликуй:
   ```json
   {
     "rules": {
       "sync": {
         "$c": {
           ".read": "$c.length >= 16",
           ".write": "$c.length >= 16"
         }
       }
     }
   }
   ```
3. В приложении: ⚙️ Настройки → **Cloud Sync** → введи:
   - **Database URL** — адрес из Firebase
   - **Sync Code** — общий код (≥16 символов)
   - **🔒 Пароль шифрования** — твой личный пароль
4. На втором устройстве введи те же три значения (или используй кнопку «Copy key for 2nd device»).

> 🔐 **Безопасность:** данные шифруются на устройстве (AES-256-GCM, ключ через PBKDF2). В облако попадает только зашифрованный конверт `{enc, iv, ct}`. Без пароля данные не прочитать даже при полном доступе к базе. **Забытый пароль не восстанавливается.**

## 🔐 Как устроено шифрование

Код шифрования открыт (он в `index.html`), но это безопасно — по принципу Керкгоффса стойкость держится не на секретности алгоритма, а на пароле. Пароль **не хранится в файле**: он вводится пользователем и живёт только в его браузере (`localStorage`). У каждого пользователя свой пароль, своя база и свои данные — общий только код приложения.

| Слой | Что используется |
|---|---|
| Вывод ключа | PBKDF2, SHA-256, 120 000 итераций, соль из Sync Code |
| Шифрование | AES-256-GCM со случайным IV на каждую запись |
| Хранение в облаке | `{enc:1, v:1, iv, ct, _t}` — без открытого текста |
