Заморозка по привычке

Ограниченное число дней в месяц, которые можно заморозить именно для ЭТОЙ привычки — настоящий ноль, не в плюс и не в минус, серию не трогает. Работает и для прошлых, и для будущих дней.

Уровни срыва (необязательно)

По умолчанию любой пропуск = −3×вес. Добавь уровни, если хочешь различать лёгкий и тяжёлый срыв (напр. «не цельное» −1×вес, «джанк» −5×вес).

Уровни успеха (необязательно)

По умолчанию любая галочка = +1×вес. Добавь уровни, если хочешь награждать разные варианты выполнения по-разному (напр. «холодный душ» +1×вес, «холодная ванна» +2×вес) — засчитывается только ОДИН уровень в день, даже если сделал несколько.

How to create a database (once, ~3 min) ▾
  1. Open console.firebase.google.com, sign in with Google.
  2. Create project → any name → disable analytics → create.
  3. Left panel: Build → Realtime Database → Create → any region → test mode.
  4. Rules tab → paste and publish:
{ "rules": { "sync": { "$c": { ".read": "$c.length >= 16", ".write": "$c.length >= 16" } } } }
